What fix.sh changed

  1. Plugins.Removed 3 plugins nothing used (Smart Slider 3, WPForms Lite, Font Awesome); Instagram Feed and Contact Form 7 files load only where they are used.
  2. Images.12 camera-size JPEGs (24 MB) → WebP at max 1920 px, real srcset sizes, lazy-loading below the fold, hero preloaded with fetchpriority=high.
  3. Caching.Page cache (Cache Enabler), gzip, and browser-cache headers in .htaccess.
  4. Fonts.Three Google Font families served from the site itself with font-display: swap; emoji script off.
  5. JavaScript.Every script deferred; WordPress keeps one blocking only where inline code needs it.
  6. Database.Old revisions, expired transients and spam comments deleted; tables optimised.
